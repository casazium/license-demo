Casazium License demo

A desktop app using License Server the way yours would. Every call it makes is listed on the right.

The server's signing key has changed. This app pinned a different public key. Offline license files signed with the old key won't verify, and a key you didn't expect to change can mean the app is talking to a different server.

License

Activate once per machine. On every start the app checks the license and that this machine is still activated.

Demo keys

States you can't reach with your own key: revoked, expired, a higher tier. Shared by everyone trying the demo, so they're only checked - never activated.

Machines

The demo license allows two machines. These buttons act as other computers would, so one machine can show the limit and a seat freed from somewhere else.

Offline

A signed license file, verified with the server's public key alone. No network needed.
