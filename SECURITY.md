# Security

If you find a security problem in this app, or in how it uses Casazium
License Server, please report it privately through
[casazium.com/contact](https://casazium.com/contact) rather than in a
public issue. We'll reply, and credit you if you'd like.

This is a demo and a reference integration. Its demo server holds only
test licenses from Stripe test-mode purchases, and is reset daily.
